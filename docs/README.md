# Docs Folder

This folder keeps project documents out of the main code root.

Contents:

- `fine_tuning_training_runbook.md`: exact site steps, project names, field values, and launch commands for training NeMo and pyannote projects
- `integration_testing_guide.md`: manual end-to-end validation steps
- `reference_materials/`: local PDFs and background reading used while shaping the workflow

The root `README.md` is still the main user guide.
